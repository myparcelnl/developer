## Inleiding

Activeer op een simpele manier Spring-contracten in de MyParcel MyContracts omgeving.

### Stappen

Om een contract voor Spring in te laden, dien je de volgende stappen uit te voeren:

1. Neem contact op met Spring en vraag om de volgende gegevens:
   - API key
   - API key voor retourzendingen (optioneel). Deze heb je alleen nodig als je retourzendingen via Spring wilt versturen.
2. Vul de volgende gegevens in op de [MyParcel backoffice MyContracts](https://backoffice.myparcel.nl/settings/account/orders-shipping) pagina en bevestig met `Activeren`:

   - `Bedrijfsnaam`: de naam van je bedrijf
   - `API Key`: de API key van Spring
   - `API Key retourzendingen`: de API key van Spring voor retourzendingen (optioneel)

   <MPImg src="/backoffice/spring/spring-instellingen.png" alt="Spring instellingen in MyParcel backoffice" />

Na bevestiging worden een aantal controles uitgevoerd en is het contract direct bruikbaar om zendingen mee aan te maken.
